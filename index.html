Developer Quick Start Guide

Launch any microservice locally from your terminal in its respective directory.

1. Voice Studio & Humanizer

Node / Express Services

Standard npm dev or start scripts:

cd VoiceStudio && npm run dev cd TextHumanizer && npm start
2. Ductus & Ident

React + Vite Frontends

Start independent Vite dev servers on assigned ports:

cd "Ductus (FLOWCHART)" && npm run dev -- --port 3002 cd "Ident - Brand Naming Studio" && npm run dev -- --port 3003
3. MediaDrop & PhotoNarrator

Full-Stack Python & Next.js

Execute local server runners:

cd MediaDrop && npm run dev cd PhotoNarrator && npm run dev
